# چک‌لیست QA کد تخفیف (تلگرام)

این سند برای تست دستی پس از deploy یا تغییرات RTL/تخفیف استفاده می‌شود.

## پیش‌نیاز

1. در پنل ادمین → تنظیمات، `system_language=fa` باشد.
2. ربات را ری‌استارت کنید: `python3 main.py`
3. حداقل یک ادمین با دسترسی `sales.discounts` داشته باشید.
4. یک کاربر تست با موجودی کافی در کیف پول.

---

## بخش ادمین

### لیست و RTL

- [ ] منوی ادمین → فروش → **کدهای تخفیف**
- [ ] عنوان و هر آیتم لیست **راست‌چین** و فارسی هستند (نه چپ‌چین انگلیسی).
- [ ] نام انگلیسی کد (مثلاً `Expired`) خط را LTR نمی‌کند؛ برچسب‌ها فارسی می‌مانند.
- [ ] خط جداکننده `━━━━━━━━━━` مرتب نمایش داده می‌شود.

### ایجاد کد

- [ ] **ایجاد کد تخفیف** → نوع **درصدی** → نام → کد → درصد → سقف هر کاربر → **بدون انقضا**
- [ ] پیام موفقیت فارسی و RTL است.
- [ ] دوباره ایجاد: نوع **مبلغ ثابت** → انقضا **۱ دقیقه** → پس از ۱ دقیقه در لیست **«منقضی شده — …»** دیده شود.

### ویرایش / toggle / حذف

- [ ] **ویرایش** → تغییر نام → ذخیره → نام در لیست به‌روز شود.
- [ ] **ویرایش** → تغییر سقف هر کاربر → ذخیره.
- [ ] **Toggle** → وضعیت در لیست «غیرفعال» شود؛ دوباره toggle → «فعال».
- [ ] **حذف** کد بدون استفاده → از لیست حذف شود.

## بخش کاربر

### خرید OVPN

- [ ] خرید سرویس → **بدون کد تخفیف** → خرید با قیمت کامل.
- [ ] خرید سرویس → **وارد کردن کد تخفیف** → کد معتبر → تخفیف در تأیید نمایش داده شود → خرید موفق.
- [ ] تاریخچه: خط کد تخفیف + تفکیک قیمت اصلی / تخفیف / نهایی.

### خرید WireGuard

- [ ] همان سناریوهای skip / enter / خرید با تخفیف.

### شارژ کیف پول

- [ ] شارژ → کد تخفیف (در صورت پشتیبانی جریان) → فیش / تأیید.

### تمدید OVPN / WG

- [ ] تمدید → prompt کد تخفیف → skip یا enter → تأیید با قیمت درست.

### پیام‌های خطا (فارسی)

- [ ] کد **منقضی** → «منقضی یا غیرفعال»
- [ ] کد **غیرفعال** (toggle off) → همان یا معادل
- [ ] **سقف استفاده** برای کاربر → پیام limit
- [ ] **۱۰+ تلاش ناموفق** پشت سر هم → rate limit
